## Lesson 14.1 — Where do game sounds come from?

| Option | Cost | Watch out for |
|---|---|---|
| Record or design your own | time | needs equipment and skill |
| Buy a pack | money | read the licence (often fine for games, never for resale) |
| **Free packs** (OpenGameArt, Kenney, freesound…) | free | **licences vary**: CC0, CC-BY (credit required), CC-BY-SA (share-alike), "non-commercial"… |
| Generate them with code | time | sounds "synthetic" unless done carefully |

Dark City uses two of these: **CC0 sound effects** and **music generated by code**.

### 🔤 Licences in one minute
* **CC0**: public domain. Use it for anything, no credit needed (crediting is still polite).
* **CC-BY**: free, but you **must credit** the author where players can see it.
* **CC-BY-SA**: credit, *and* things you make from it must use the same licence. That's awkward
  for a game.
* **CC-BY-NC**: non-commercial only. You can't sell the game.

Always keep a note of **where each file came from and under which licence**. We put ours in the
import script itself, in `docs/audio/README.md`, and in the in-game CREDITS.

The pack used here: *The Essential Retro Video Game Sound Effects Collection [512 sounds]* by
**Juhani Junkala**, CC0, on OpenGameArt. Its `INFO.txt` says: *"These sound effects have been
released under CC0 creative commons license."*

## Lesson 14.2 — A repeatable import script

512 files, of which we want 30, each with a sensible name and a similar loudness. Doing this by
hand is boring, and you'd have to do it again whenever you change your mind. So we write a script.

```bash
#!/usr/bin/env bash
set -euo pipefail
SRC="${1:?give the extracted pack folder}"
OUT="$(cd "$(dirname "$0")/../.." && pwd)/asset/audio/sfx"
mkdir -p "$OUT"
```
*(from the game: `tools/audio/import_sfx.sh`)*

* **`set -euo pipefail`**: stop at the first error (`-e`), treat unset variables as errors (`-u`),
  and fail if any part of a pipe fails. Always start bash scripts with this.
* **`${1:?message}`**: the first argument, or stop with that message if it's missing.
* **`OUT=...`**: `$(dirname "$0")` is the folder of the script (`tools/audio`); `/../..` goes up to
  the project. The script works from any current directory.

```bash
MAP=(
  "shoot|Weapons/Single Shot Sounds/sfx_weapon_singleshot2.wav"
  "enemy_shoot|Weapons/Single Shot Sounds/sfx_weapon_singleshot7.wav"
  "reload|Weapons/Out of Ammo/sfx_wpn_reload.wav"
  ...
)
for row in "${MAP[@]}"; do
  name="${row%%|*}"; file="${row#*|}"
  ffmpeg -v error -y -i "$SRC/$file" -af "loudnorm=I=-16:TP=-1.5" -ar 44100 -ac 1 "$OUT/$name.wav"
  echo "  $name  <-  $file"
done
```
*(from the game)*

* The table is **data**: `game_name|path in pack`. To swap a sound, change one row and re-run.
* `${row%%|*}` = everything before the first `|`; `${row#*|}` = everything after it. (Bash's
  built-in string cutting.)
* **`ffmpeg -af loudnorm=I=-16:TP=-1.5`**: the *loudness normalisation* filter. It measures how
  loud the sound *feels* (in LUFS, which follows human hearing) and adjusts it to −16 LUFS, keeping
  peaks under −1.5 dB. After this, every effect starts at a similar perceived volume, and the
  per-sound mix in Godot (lesson 14.4) only needs small tweaks.
* `-ar 44100 -ac 1`: 44.1 kHz, mono. Positional sound is panned by Godot, so the source should be
  mono.

### Making a new sound from an old one

There was no thunder in the pack. A long explosion, slowed down and muffled, sounds a lot like it:

```bash
ffmpeg -v error -y -i "$SRC/Explosions/Long/sfx_exp_long5.wav" \
  -af "asetrate=22050,aresample=44100,lowpass=f=700,volume=2.0,afade=t=out:st=4:d=4" "$OUT/thunder.wav"
```
*(from the game)*

* `asetrate=22050,aresample=44100`: pretend the 44.1 kHz file is 22 kHz (plays at half speed, an
  octave lower), then convert back to a normal rate.
* `lowpass=f=700`: remove the highs. Distant sounds lose their high frequencies first.
* `afade=t=out:st=4:d=4`: fade out over 4 s starting at 4 s, for a rumbling tail.

### 🔤 WAV or Ogg?
| | WAV | Ogg Vorbis |
|---|---|---|
| Size | big (uncompressed) | ~10× smaller |
| CPU to play | almost none | some (decoding) |
| Use for | short sound effects | music, long loops |

Godot imports `.wav` as `AudioStreamWAV` and `.ogg` as `AudioStreamOggVorbis`. After adding files,
open the editor or run `godot --headless --import`.

## Lesson 14.3 — Buses and decibels

Godot mixes sound through **buses**, like a mixing desk. Every player sends to a bus, buses send to
`Master`, and `Master` goes to the speakers.

```
 shoot, explosion…  ──► SFX ─────┐
 music players      ──► Music ───┤  (Music has a low-pass filter, used while paused)
 rain loop          ──► Ambience ├──► Master ──► speakers
 menu blips         ──► UI ──────┘
```

One bus per *kind* of sound gives one volume slider per kind. "I want the music quieter but the
gunshots loud" is the most common audio request from players.

```gdscript
func _make_buses() -> void:
	for bus_name in BUSES:
		if AudioServer.get_bus_index(bus_name) == -1:
			AudioServer.add_bus()
			var i := AudioServer.bus_count - 1
			AudioServer.set_bus_name(i, bus_name)
			AudioServer.set_bus_send(i, "Master")
	_music_bus = AudioServer.get_bus_index("Music")
	if AudioServer.get_bus_effect_count(_music_bus) == 0:
		var lp := AudioEffectLowPassFilter.new()
		lp.cutoff_hz = 900.0
		AudioServer.add_bus_effect(_music_bus, lp)
	AudioServer.set_bus_effect_enabled(_music_bus, 0, false)
```
*(from the game: `scripts/autoload/audio.gd`)*

* **`AudioServer`** is the engine's audio singleton. Buses are numbered; `get_bus_index(name)`
  returns −1 if it doesn't exist.
* `add_bus()` appends a bus at the end, so its index is `bus_count - 1`.
* The **low-pass filter** removes frequencies above 900 Hz. It's added once and switched on/off
  later with `set_bus_effect_enabled`.
* You can also build buses in the editor's **Audio** panel (saved as `default_bus_layout.tres`).
  Doing it in code keeps the whole audio setup readable in one file.

### 🔤 Decibels and `linear_to_db`
Volume in audio is measured in **decibels (dB)**, a *logarithmic* scale. 0 dB = unchanged,
−6 dB ≈ half the amplitude, −20 dB = a tenth, −80 dB ≈ silence.

Our slider is *linear* (0–100 %). Converting:

```gdscript
func _set_bus_volume(bus_name: String, percent: int) -> void:
	var i := AudioServer.get_bus_index(bus_name)
	AudioServer.set_bus_mute(i, percent <= 0)
	AudioServer.set_bus_volume_db(i, linear_to_db(percent / 100.0) if percent > 0 else -80.0)
```
*(from the game)*

`linear_to_db(0.5)` = −6.02 dB. `linear_to_db(0)` would be −∞, which is why 0 % mutes the bus
instead. If you mapped 0–100 % straight onto −80…0 dB, the slider would do almost nothing in its
upper half and drop off a cliff at the bottom.

### 🧪 Try it
Run the game, open SETTINGS → AUDIO, and drag *Music* down slowly. With the dB conversion the
volume falls evenly. Now temporarily change the code to
`set_bus_volume_db(i, lerpf(-80, 0, percent / 100.0))` and drag again. Hear the difference?

## Lesson 14.4 — The `Audio` autoload

```gdscript
const POOL_SIZE := 12

func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS   # menu sounds and music work while paused
	_make_buses()
	for i in 2:
		var m := AudioStreamPlayer.new()
		m.bus = "Music"
		add_child(m)
		_music.append(m)
	for i in POOL_SIZE:
		var p := AudioStreamPlayer.new()
		p.bus = "SFX"
		add_child(p)
		_pool.append(p)
		var p2 := AudioStreamPlayer2D.new()
		p2.bus = "SFX"
		p2.max_distance = 520.0
		p2.attenuation = 1.4
		p2.panning_strength = 0.7
		add_child(p2)
		_pool_2d.append(p2)
	...
	Settings.changed.connect(_on_setting_changed)
	apply_volumes()
```
*(from the game)*

* **`PROCESS_MODE_ALWAYS`**: a paused tree pauses audio players too, unless they're allowed to
  run. We want menu blips and (muffled) music in the pause menu.
* **Two music players** for cross-fading (lesson 14.5).
* **A pool of 12 + 12 effect players**, created once. Why not `AudioStreamPlayer.new()` for each
  gunshot? Creating and freeing nodes 7 times a second is wasteful, and you'd have to free them
  when the sound ends. A pool reuses players in a circle.
* **`AudioStreamPlayer2D`** is *positional*: it knows where it is in the world and where the camera
  is. `max_distance = 520` (a bit more than the 384 px screen width) means off-screen fights are
  still faintly audible. `attenuation` shapes how fast it gets quieter. `panning_strength = 0.7`
  pans left/right, but not completely (full panning in headphones is tiring).

### Playing an effect

```gdscript
const SFX := {
	"shoot": {"db": -8.0, "pitch": 0.08},
	"explosion": {"db": -2.0, "pitch": 0.12},
	"thunder": {"db": -6.0, "pitch": 0.15},
	...
}

func sfx(sound: String, at: Variant = null, pitch: float = 1.0, extra_db: float = 0.0) -> void:
	var stream := _stream(SFX_DIR + sound + ".wav")
	if stream == null:
		return
	var mix: Dictionary = SFX.get(sound, {"db": -6.0, "pitch": 0.0})
	var p: Node
	if at is Vector2 and get_viewport().get_camera_2d() != null:
		var p2 := _pool_2d[_pool_next]
		p2.global_position = at
		p = p2
	else:
		p = _pool[_pool_next]
	_pool_next = (_pool_next + 1) % POOL_SIZE
	p.stream = stream
	p.volume_db = mix.db + extra_db
	p.pitch_scale = pitch * (1.0 + randf_range(-mix.pitch, mix.pitch))
	p.play()
```
*(from the game)*

Line by line:

1. **`at: Variant = null`**: an optional position. `Variant` lets us pass either nothing or a
   `Vector2`, and `at is Vector2` checks which.
2. `_stream(path)` loads the file once and caches it in a dictionary:
   ```gdscript
   func _stream(path: String) -> AudioStream:
   	if not _streams.has(path):
   		_streams[path] = load(path) if ResourceLoader.exists(path) else null
   	return _streams[path]
   ```
   `ResourceLoader.exists` first, so a typo in a sound name gives silence instead of an error
   storm.
3. **The mix table** gives each sound its own volume. A gunshot at full volume 7 times a second
   would drown everything; a once-a-minute boss explosion can be loud.
4. **No camera, no positional sound:** on the title and in the intro there's no `Camera2D`, so the
   plain player is used.
5. `(_pool_next + 1) % POOL_SIZE`: round-robin. After player 11 comes player 0. If 13 sounds
   overlap, the 13th cuts off the oldest, which nobody notices in a firefight.
6. **Random pitch** (`±8 %` for shots): the cheapest trick in game audio. The same sample 200 times
   in a row sounds like a machine gun from a toy; slight variation sounds alive.

### Using it from gameplay code

One line per event:

```gdscript
# player.gd
	Audio.sfx("shoot", global_position)                 # in _shoot()
	Audio.sfx("player_hurt", global_position)           # in take_damage()
	Settings.rumble(0.5, 0.8, 0.25)
	Audio.sfx("pickup_" + kind, global_position)        # in collect(): pickup_health / pickup_grenade

# enemy_base.gd
	Audio.sfx("enemy_hurt", global_position)            # in take_damage()
	Audio.sfx("enemy_die", global_position)             # in die()

# bullet.gd, when hitting a wall instead of a target
	else:
		Audio.sfx("impact", global_position)
```
*(from the game)*

This is why `Audio` is an autoload: gameplay scripts never own players, never load files, never
care about buses. If you later swap every sound or the whole audio engine, none of these lines
change.

### UI sounds for every button, in one place

```gdscript
static func add_sounds(c: Control) -> void:
	c.focus_entered.connect(func() -> void: Audio.ui("ui_move"))
	c.mouse_entered.connect(func() -> void:
		if c.focus_mode != Control.FOCUS_NONE and not (c is BaseButton and c.disabled):
			c.grab_focus())
	if c is BaseButton:
		(c as BaseButton).pressed.connect(func() -> void: Audio.ui("ui_select"))
```
*(from the game, `ui_kit.gd`; `UI.button()` calls it for every button)*

* A blip when the focus moves, a click when pressed.
* **Hovering grabs the focus**, so the mouse and the keyboard/gamepad always agree on which button
  is highlighted. Without this you can end up with one button hovered and another focused.

One problem: opening a menu focuses its first button, which plays "ui_move" even though the player
didn't move. So:

```gdscript
func mute_ui(seconds: float = 0.15) -> void:
	_ui_mute_until = Time.get_ticks_msec() + int(seconds * 1000)

# ui_kit.gd
static func focus_quietly(c: Control) -> void:
	Audio.mute_ui()
	c.grab_focus()
```
*(from the game)*

`Time.get_ticks_msec()` is milliseconds since the game started. `ui()` returns early while the
current time is before `_ui_mute_until`.

## Lesson 14.5 — Music: cross-fades and moods

```gdscript
func play_music(track: String, fade: float = 1.0) -> void:
	if track == _music_name:
		return
	_music_name = track
	var stream := _stream(MUSIC_DIR + track + ".ogg")
	if stream is AudioStreamOggVorbis:
		stream.loop = track in LOOPING_MUSIC
	# A fade still running would stop the player we are about to reuse.
	if _music_tween:
		_music_tween.kill()
	var old := _music[_music_index]
	_music_index = 1 - _music_index
	var new := _music[_music_index]
	new.stream = stream
	new.volume_db = -40.0
	new.play()
	_music_tween = create_tween().set_parallel()
	_music_tween.tween_property(new, "volume_db", 0.0, fade)
	_music_tween.tween_property(old, "volume_db", -60.0, fade)
	_music_tween.chain().tween_callback(old.stop)
```
*(from the game)*

* **Same track? Do nothing.** Going title → settings → title doesn't restart the title music.
* **`stream.loop`**: Ogg streams have a `loop` property. Jingles (victory, game over) play once.
* **`1 - _music_index`** flips between 0 and 1: the classic two-deck DJ cross-fade.
* `set_parallel()` runs both fades *at the same time*. `chain()` then goes back to sequential, so
  `old.stop` runs after both fades.
* **Killing the previous tween** fixes a real bug found while writing this course: skip the intro
  and press NEW GAME within a second, and the intro→title fade's `old.stop` callback would fire
  on the player now used for the street music, cutting it off. **Whenever a tween might still be
  running, keep a reference and kill it before starting a conflicting one.**

## Lesson 14.6 — Synthesising a soundtrack

The six music tracks were made by `tools/audio/compose_music.py`: about 480 lines of Python that
only need **numpy** (and ffmpeg for the final Ogg encoding). You don't need it to play the game;
read this lesson to understand how digital sound works.

### 🔤 Digital audio in one paragraph
Sound is air pressure going up and down. A computer stores it as **samples**: numbers between −1
and +1, taken 44,100 times per second (**44.1 kHz**). A 440 Hz sine wave, the note A4, is
`sin(2π · 440 · t)` sampled at `t = 0, 1/44100, 2/44100…`. In numpy, a whole second of A4 is one
line:

```python
t = np.arange(44100) / 44100
a4 = np.sin(2 * np.pi * 440 * t)
```

### Notes and pitches

```python
NOTE = {"C": 0, "C#": 1, "Db": 1, "D": 2, ... "B": 11}

def midi(name):
    """'A4' -> 69 (MIDI note number)."""
    return 12 * (int(name[-1]) + 1) + NOTE[name[:-1]]

def mtof(m):
    """MIDI note number -> frequency in Hz."""
    return 440.0 * 2.0 ** ((m - 69) / 12.0)
```
*(from the game)*

* MIDI numbers count semitones: C4 = 60, A4 = 69.
* **Each semitone multiplies the frequency by 2^(1/12) ≈ 1.0595.** Twelve of them make 2×: one
  octave. `mtof(81)` (A5) = 880 Hz.

### Envelopes

A note isn't on/off. It rises, settles, and fades: **ADSR** (Attack, Decay, Sustain, Release).

```python
def envelope(total, gate, a, d, s, r):
    t = np.arange(total) / SR
    g = gate / SR
    attack = np.clip(t / max(a, 1e-4), 0.0, 1.0)
    decay = s + (1.0 - s) * np.exp(-np.maximum(t - a, 0.0) / max(d, 1e-4))
    env = np.where(t < a, attack, decay)
    level = env[min(gate, total - 1)] if total else 0.0
    release = level * np.exp(-np.maximum(t - g, 0.0) / max(r / 4.0, 1e-4))
    return np.where(t < g, env, release)
```
*(from the game)*

* Everything is **vectorised**: `t` is an array of every sample's time, and each line computes
  the whole curve at once. That's why numpy is fast; a Python `for` loop over 44,100 samples per
  second of audio would be very slow.
* `np.where(condition, a, b)` picks `a` or `b` per element: attack before `a` seconds, decay after.
* `gate` is when the key is "released". After it, the level decays exponentially from wherever
  it was.

### Instruments: additive synthesis

A **sawtooth** wave (bright, buzzy: the classic synth sound) is a sum of sines: the fundamental
plus every harmonic `k` at amplitude `1/k`. A **square** wave uses only odd harmonics. So:

```python
def additive(freq, total, cutoff, odd_only=False, vibrato=0.0, kmax=60):
    t = np.arange(total) / SR
    f = freq * 2.0 ** (vibrato * np.sin(2 * np.pi * 5.5 * t) * np.clip(t * 3, 0, 1) / 12.0)
    phase = 2 * np.pi * np.cumsum(f) / SR
    cmax = float(np.max(cutoff))
    top = int(min(kmax, SR / 2.2 / freq, cmax * 3.0 / freq + 1))
    out = np.zeros(total)
    for k in range(1, max(top, 1) + 1, 2 if odd_only else 1):
        weight = (1.0 / k) / (1.0 + (k * freq / cutoff) ** 4)
        out += weight * np.sin(k * phase + rng.uniform(0, 2 * np.pi))
    return out
```
*(from the game)*

* **Vibrato:** the frequency wobbles 5.5 times a second by `vibrato` semitones, fading in over
  the first 0.33 s (`clip(t * 3, 0, 1)`), the way a singer adds vibrato after the note starts.
* **`np.cumsum(f) / SR`**: when the frequency changes over time, you can't use `sin(2π·f·t)`. You
  must *add up* the frequency sample by sample to get the phase. `cumsum` does exactly that.
* **`SR / 2.2 / freq`**: never generate harmonics above about half the sample rate (the *Nyquist*
  limit). Above it they fold back as ugly, out-of-tune tones (aliasing). Building the wave from
  harmonics makes this trivial: we just stop adding them.
* **The filter is built into the weights:** `1 / (1 + (k·f / cutoff)⁴)` is ≈ 1 for harmonics below
  `cutoff` and falls steeply above it: a 24 dB/octave **low-pass filter**, computed for free.
* **`cutoff` can be an array.** Pass a falling curve and the sound starts bright and darkens. That
  "pluck" is the signature synth sound:

```python
def pluck(m, dur, bright=3200.0):
    total = samples(dur + 0.3)
    t = np.arange(total) / SR
    cutoff = 250.0 + bright * np.exp(-t / 0.09)
    return 0.5 * additive(mtof(m), total, cutoff) * envelope(total, samples(dur), 0.002, 0.25, 0.0, 0.15)
```
*(from the game)*

The other instruments are variations: `pad` = three slightly detuned saws (±9 cents, which gives a
chorus-like width) with a slow filter wobble; `bass` = saw + sine; `lead` = a saw/square blend with
vibrato; `bell` = three sines at *inharmonic* ratios (1, 2.76, 5.4), which is what makes metal
sound like metal.

### Drums from noise and sweeps

```python
def kick(level=1.0):
    total = samples(0.45)
    t = np.arange(total) / SR
    f = 45.0 + 110.0 * np.exp(-t / 0.035)
    body = np.sin(2 * np.pi * np.cumsum(f) / SR) * np.exp(-t / 0.18)
    click = fft_filter(rng.standard_normal(total), lo=2000) * np.exp(-t / 0.004) * 0.3
    return level * 0.9 * np.tanh(1.5 * (body + click))
```
*(from the game)*

* A **kick drum** is a sine whose pitch drops fast (155 → 45 Hz in a few tens of milliseconds)
  plus a tiny burst of high noise for the "click" of the beater.
* `np.tanh` gently squashes peaks: **soft clipping**, which adds punch and warmth.
* A **snare** is band-passed noise plus a short 185 Hz tone. A **hi-hat** is high-passed noise
  that dies in 18 ms.

`fft_filter` filters in the frequency domain: FFT → multiply each frequency by a gain → inverse
FFT. An FFT treats the signal as if it repeats forever, which matters below.

### The tracker: songs, buses and seamless loops

```python
class Song:
    def __init__(self, bpm, bars, loop=True, tail=0.0):
        self.spb = 60.0 / bpm
        self.loop = loop
        self.length = samples(bars * 4 * self.spb + (0 if loop else tail))
        self.buses = {}
        self.kicks = []

    def add(self, bus, beat, sig, pan=0.0):
        buf = self.buses.setdefault(bus, np.zeros((2, self.length)))
        start = self.beat_to_sample(beat)
        sig = sig[: self.length]
        idx = np.arange(len(sig)) + start
        if self.loop:
            idx %= self.length            # the tail of the last note wraps to the start
        else:
            keep = idx < self.length
            idx, sig = idx[keep], sig[keep]
        left, right = np.cos((pan + 1) * np.pi / 4), np.sin((pan + 1) * np.pi / 4)
        buf[0, idx] += sig * left
        buf[1, idx] += sig * right
```
*(from the game)*

* `spb` = seconds per beat (0.536 s at 112 BPM). Positions are in **beats**, so melodies read
  like sheet music: `(8, 1.5, "A4")` is "A4 on beat 8, 1.5 beats long".
* Each **bus** is a stereo array (`2 × length`). `setdefault` creates it on first use.
* **`idx %= self.length` is the seamless-loop trick.** The last note of bar 16 rings past the end
  of the song. Instead of being cut off (a click at the loop point), its tail is added to the
  *start* of the song. When the game loops the file, the tail continues exactly where it should.
* **Equal-power panning:** `cos/sin` of an angle keep the total loudness constant as a sound moves
  from left to right.

Writing a track then looks like this:

```python
def street_theme():
    s = Song(112, 16)
    prog = ["Em", "C", "D", "B"] * 4
    octave_jumps = [0, 0, 12, 0, 0, 12, 0, 12]
    for bar, ch in enumerate(prog):
        root = midi(CHORDS[ch][0][:-1] + "2")
        for i, jump in enumerate(octave_jumps):
            s.add("bass", bar * 4 + i * 0.5, bass(root + jump, 0.45 * s.spb))
        ...
        s.pattern(bar, "k...k...k...k...|....s.......s...|h.h.h.h.h.h.h.h.")
```
*(from the game)*

* A **chord progression** (Em – C – D – B, i–VI–VII–V in E minor) repeated four times.
* The bass plays 8th notes on the chord's root, jumping an octave on some steps: a driving,
  "running" bass line.
* **Drum patterns as strings**: one character per 16th note. `k` kick, `s` snare, `h` hat, `.`
  rest. You can *see* the four-on-the-floor kick and the snare on beats 2 and 4.

### Effects

**Sidechain ducking** makes the pads dip every time the kick hits, the "pumping" sound of
electronic music, and it keeps the kick clear:

```python
    def sidechain(self, bus, depth=0.6, release=0.18):
        t = np.arange(self.length)
        duck = np.ones(self.length)
        for b in self.kicks:
            d = (t - self.beat_to_sample(b)) % self.length if self.loop else t - self.beat_to_sample(b)
            mask = (d >= 0) & (d < SR)
            duck[mask] = np.minimum(duck[mask], 1 - depth * np.exp(-d[mask] / (release * SR)))
        self.buses[bus] *= duck
```
*(from the game)*

**Ping-pong delay** with `np.roll` (which shifts an array *circularly*, so echoes wrap around the
loop too) and swapping the channels each echo:

```python
        for i in range(1, 6):
            echo = np.roll(echo, d, axis=1) * feedback
            echo = echo[::-1]                       # swap channels = ping-pong
            wet += echo
```
*(from the game)*

**Convolution reverb:** a room's reverb is what you'd hear after a single clap: an *impulse
response*. Ours is decaying filtered noise. Convolving the music with it adds the room. Done with
FFTs, convolution is a multiplication:

```python
            n = self.length if self.loop else self.length + ir_len
            wet_ch = np.fft.irfft(np.fft.rfft(send[ch], n) * np.fft.rfft(ir, n), n)
```
*(from the game)*

With `n = self.length`, FFT convolution is **circular**: the reverb tail of the last bar wraps into
the first, which is exactly what a seamless loop needs.

### Mastering and encoding

```python
        mix = dry + wet * 0.8
        mix = np.tanh(drive * mix / max(np.max(np.abs(mix)), 1e-9) * 1.4)
        return mix / np.max(np.abs(mix)) * 0.89  # about -1 dBFS
```
*(from the game)*

Normalise, soft-clip with `tanh` (glues the mix, tames peaks), normalise again to 0.89 (≈ −1 dB
below full scale, which leaves headroom for the lossy encoder). Then write a 16-bit WAV with
Python's `wave` module and let `ffmpeg -c:a libvorbis -q:a 5` make the `.ogg`.

## 📝 Recap

* **Check licences** and record every file's source. CC0 is the easiest.
* **Script your asset preparation** (`import_sfx.sh`): repeatable, reviewable, easy to change.
* **Loudness-normalise** effects first, then fine-tune per sound in one table.
* **Buses** = one slider per kind of sound. Sliders are linear, so convert with `linear_to_db`.
* An **`Audio` autoload** owns every player: a round-robin **pool** for effects, two players for
  **cross-fading** music, positional `AudioStreamPlayer2D` for world sounds.
* **Random pitch** on repeated sounds; **silence** before a boss theme; **muffle** on pause.
* **Kill a running tween** before starting one that touches the same nodes.
* Digital audio is arrays of samples. **Additive synthesis**, **envelopes**, **noise drums**,
  **circular** mixing and convolution give seamless, original, deterministic music.
