# Chapter 10 — Building the level

🎯 **Goals**
* Paint tiles from code with `TileMapLayer.set_cell`.
* Generate a level **from data tables**, with **seeded randomness** for decoration.
* Save a node tree built in code as a `.tscn` with `PackedScene.pack` (and understand `owner`).
* Create depth with `CanvasLayer`, `z_index`, `Parallax2D` and `CanvasModulate`.
* Draw custom graphics with `_draw()` (stars and moon) and add rain with particles.
* Build the **boss arena**: triggers, walls, camera locks, spawning, and signal-driven cleanup.

---

## Lesson 10.1 — Hand-built or generated?

You could build the whole street in the editor: paint 700 tiles, place 100 building sprites, drag
19 enemies. Instead, Dark City **generates** `level_1.tscn` with a tool script. The result is still
a normal scene you can open and edit.

| | Hand-built in the editor | Generated by `build_level.gd` |
|---|---|---|
| See while you work | ✔ | after a rebuild |
| Change "all pits 1 tile wider" | tedious | edit one array, rebuild |
| Consistent decoration | depends on patience | rules + seeded RNG |
| Fine artistic control | ✔ | edit the scene afterwards (but a rebuild overwrites it) |

A common professional compromise is what this project does: **generate the bulk, then polish by
hand**, and stop regenerating once you start polishing.

## Lesson 10.2 — The level as data

```gdscript
extends Node
## Asset pipeline step 2: builds res://scenes/level/level_1.tscn.
##
## Run AFTER build_resources.gd (as a scene, so the Game autoload exists):
##   godot --headless res://tools/build_level.tscn
## ...
## WARNING: re-running this script overwrites manual edits to level_1.tscn.

const T := 16
const GROUND_ROW := 11          # top of the ground = y 176
const LEVEL_TILES := 236        # 236 * 16 = 3776 px
const OUT := "res://scenes/level/level_1.tscn"

const TILES := preload("res://asset/Tiled/Tile1.png")
```

*(from the game)*

**Why run as a scene (`build_level.tscn`, a `Node` with this script) instead of `--script`?**
Instantiating the player, enemies and HUD runs nothing yet, but their scripts reference `Game`.
Scripts are compiled when loaded, and `Game` only exists as a global when autoloads are loaded,
which happens when you run a scene, not with `--script`.

> ✋ The HUD scene comes in chapter 11. To run the builder now, create a placeholder
> `scenes/ui/hud.tscn` (a `CanvasLayer` with no script), or comment out the HUD lines.

### Level design notes hidden in the numbers
* **A pit sits under a platform** (pit tiles 34–36, platform at 33–37): the platform is the safe
  route over the gap.
* **Rows 9 and 7** are 2 and 4 tiles above the ground. Row 9 is reachable from the floor (jump
  height ≈ 3 tiles). Row 7 needs a hop from row 9, which makes a small climbing challenge.
* **Two platforms in each arena** give the player escape routes from charges and shockwaves
  (bosses can't stand on platforms, as you saw in chapter 9).
* **Enemies at y 112** stand on row-7 platforms. Gunners up high shoot down over the street.
* **A health pickup just before each arena** (760, 2040, 3300) lets you enter boss fights healthy.

## Lesson 10.3 — Building the tree and saving it

```gdscript
var rng := RandomNumberGenerator.new()
var level_root: Node2D


func _ready() -> void:
	rng.seed = 2026
	level_root = Node2D.new()
	level_root.name = "Level1"
	level_root.set_script(load("res://scripts/level/level.gd"))
	level_root.level_width = LEVEL_TILES * T

	_build_sky()
	_build_parallax()
	_build_street_decor()
	_build_tiles()
	_build_bounds()
	_build_rain()

	var tint := CanvasModulate.new()
	tint.name = "NightTint"
	tint.color = Color(0.8, 0.77, 0.95)
	_add(level_root, tint)

	var player := PLAYER.instantiate()
	player.position = Vector2(40, GROUND_ROW * T)
	_add(level_root, player)
	...
```
*(from the game)*

* **`rng.seed = 2026`**: a `RandomNumberGenerator` with a fixed seed produces the **same
  sequence** of "random" numbers every run. The street looks random but rebuilds identically. Change
  the seed for a different street. (The global `randf()` is seeded randomly at startup, which is
  why the game's AI uses it, while the builder uses its own `rng`.)
* **`set_script()`** attaches `level.gd` to the root built in code. After that, its exported
  `level_width` property exists and can be set.

```gdscript
	for a in ARENAS:
		var arena := ARENA.instantiate()
		arena.name = "BossArena%d" % (ARENAS.find(a) + 1)
		arena.position = Vector2(a[0] * T, GROUND_ROW * T)
		arena.boss_scene = load(a[1])
		arena.reward = a[2]
		_add(level_root, arena)

	var enemies := _add(level_root, Node2D.new(), "Enemies")
	for e in ENEMIES:
		var n := (GUNNER if e[0] == "gunner" else BRUTE).instantiate()
		n.position = Vector2(e[1], e[2])
		_add(enemies, n)

	var pickups := _add(level_root, Node2D.new(), "Pickups")
	for p in PICKUPS:
		var n := PICKUP.instantiate()
		n.kind = p[0]
		n.expires = false
		n.position = Vector2(p[1], p[2])
		_add(pickups, n)

	_add(level_root, HUD.instantiate())

	var packed := PackedScene.new()
	var err := packed.pack(level_root)
	if err == OK:
		err = ResourceSaver.save(packed, OUT)
	print("build_level: saved %s (error code %d)" % [OUT, err])
	level_root.free()
	get_tree().quit()
```
*(from the game)*

* **Container nodes** (`Enemies`, `Pickups`) keep the scene tree tidy and collapsible.
* **Placed pickups never expire**, unlike dropped loot.
* **`PackedScene.pack(root)`** serialises a node tree into a scene resource, and `ResourceSaver`
  writes it to disk.
* `level_root.free()`: the tree was never added to the SceneTree, so we free it immediately
  (`queue_free` needs the tree).

### 🔤 The `owner` rule

```gdscript
## Adds a node and sets its owner so it gets saved into the scene file.
func _add(parent: Node, node: Node, node_name: String = "") -> Node:
	if node_name != "":
		node.name = node_name
	parent.add_child(node, true)
	node.owner = level_root
	return node
```
*(from the game)*

`pack()` saves **only nodes whose `owner` is the root** (plus the root itself). Nodes without an
owner are treated as temporary helpers and skipped. That's how the editor avoids saving things like
gizmos. Forgetting `owner` is the #1 reason "my generated scene is empty". The helper sets it for
every node, every time.

* `add_child(node, true)`: the `true` asks Godot to give **readable unique names** (`Sprite2D2`,
  `Sprite2D3`…) when names collide.
* For **instanced** scenes (player, enemies), setting the owner of the instance root is enough.
  The instance's own children stay owned by their scene and are saved as a reference to it, not
  duplicated.

## Lesson 10.4 — Tiles: `set_cell`

```gdscript
func _build_tiles() -> void:
	var ground := TileMapLayer.new()
	ground.tile_set = TILESET
	ground.modulate = Color(0.78, 0.76, 0.85)
	_add(level_root, ground, "Ground")
	var platforms := TileMapLayer.new()
	platforms.tile_set = TILESET
	_add(level_root, platforms, "Platforms")

	for tx in range(-2, LEVEL_TILES + 2):
		var in_pit := false
		for p in PITS:
			if tx >= p[0] and tx < p[1]:
				in_pit = true
		if in_pit:
			continue
		ground.set_cell(Vector2i(tx, GROUND_ROW), 0, Vector2i(1 + rng.randi() % 4, 22))
		ground.set_cell(Vector2i(tx, GROUND_ROW + 1), 0, Vector2i(6 + rng.randi() % 4, 26 + rng.randi() % 3))
		ground.set_cell(Vector2i(tx, GROUND_ROW + 2), 0, Vector2i(1 + rng.randi() % 4, 26 + rng.randi() % 3))

	for p in PLATFORMS:
		var length: int = p[2]
		for k in length:
			var atlas := Vector2i(13 + rng.randi() % 8, 15)
			if k == 0:
				atlas = Vector2i(12, 15)
			elif k == length - 1:
				atlas = Vector2i(22, 15)
			platforms.set_cell(Vector2i(p[0] + k, p[1]), 0, atlas)
```
*(from the game)*

`set_cell(coords, source_id, atlas_coords)`:
* `coords`: **map** cell (column, row) in the level.
* `source_id` `0`: the atlas source we registered in chapter 4.
* `atlas_coords`: which tile from the sheet.

Details worth noticing:
* **`TileMapLayer`** (Godot 4.3+) is one layer per node. Two nodes, `Ground` and `Platforms`, keep
  solid and one-way tiles separate and easy to edit.
* `range(-2, LEVEL_TILES + 2)`: two extra tiles past each end, so the camera edge never shows a gap.
* **Random variants:** `1 + rng.randi() % 4` picks a column from 1 to 4. A row of identical tiles
  looks artificial, and variety costs nothing.
* **Platforms** get caps: the left end uses tile 12, the right end tile 22, and the middle is random
  13–20. Three pieces make any length look finished.
* `var length: int = p[2]`: elements of an untyped array are `Variant`, so the explicit type
  makes `length` an `int` for the comparison `k == length - 1`.

## Lesson 10.5 — Decoration with sprites

```gdscript
func _sprite(parent: Node, region: Rect2, bottom_left: Vector2, tint := Color.WHITE) -> Sprite2D:
	var s := Sprite2D.new()
	s.texture = TILES
	s.region_enabled = true
	s.region_rect = region
	s.centered = false
	s.position = bottom_left - Vector2(0, region.size.y)
	s.modulate = tint
	_add(parent, s)
	return s
```
*(from the game)*

* `region_enabled` + `region_rect` shows a piece of a big texture directly on a `Sprite2D`
  (the alternative is an `AtlasTexture`, as in the pickup).
* **Placing by bottom-left:** buildings stand on the ground, so it's natural to say "put it here,
  standing on y = 176". Sprites normally position by their centre. `centered = false` uses the
  top-left, and subtracting the height converts that to bottom-left.
* `tint := Color.WHITE` is a **default parameter with an inferred type**.

```gdscript
func _build_street_decor() -> void:
	var back := _add(level_root, Node2D.new(), "Buildings")
	back.z_index = -5
	var front := _add(level_root, Node2D.new(), "Props")
	front.z_index = -2
	var ground_y := float(GROUND_ROW * T)
	var x := -20.0
	var i := 0
	while x < LEVEL_TILES * T:
		var burger := rng.randf() < 0.45
		var region := BUILDING_BURGER if burger else BUILDING_YELLOW
		var tint := Color.WHITE.darkened(rng.randf_range(0.0, 0.12))
		_sprite(back, region, Vector2(x, ground_y), tint)
		if not burger and rng.randf() < 0.6:
			_sprite(back, SIGN_VIDEO if rng.randf() < 0.5 else SIGN_BURGERS,
				Vector2(x + 24, ground_y - region.size.y), tint)
		# A couple of posters on the wall.
		for k in rng.randi_range(0, 2):
			_sprite(back, POSTERS[rng.randi() % POSTERS.size()],
				Vector2(x + rng.randf_range(10, region.size.x - 26), ground_y - rng.randf_range(20, 40)), tint)
		# Street junk in front.
		var junk: Array = PROPS.keys()
		for k in rng.randi_range(0, 2):
			var key: String = junk[rng.randi() % junk.size()]
			_sprite(front, PROPS[key], Vector2(x + rng.randf_range(0, region.size.x - 40), ground_y))
		x += region.size.x + rng.randf_range(50.0, 130.0)
		i += 1
```
*(from the game)*

**Procedural decoration** follows simple rules that produce variety:
1. Walk along the street with `x`.
2. Choose a building (45 % burger shop), darken it randomly by up to 12 % so neighbours differ.
3. Maybe add a sign, 0–2 posters and 0–2 props.
4. Skip ahead by the building width plus a random 50–130 px gap.

`for k in rng.randi_range(0, 2)` loops 0, 1 or 2 times: a random count in one line.

## Lesson 10.6 — Depth: layers, z-index and parallax

Drawing order decides what's in front. Godot gives three tools:

| Tool | Scope | Used for |
|---|---|---|
| **Tree order** | siblings: later children draw on top | default |
| **`z_index`** | within the same canvas, lower draws first | `Buildings` −5, `Props` −2, skylines −10/−9 |
| **`CanvasLayer`** | a separate canvas with its own layer number, **not moved by the camera** | sky (−20), rain (5), HUD (10) |

```gdscript
func _build_sky() -> void:
	var layer := _add(level_root, CanvasLayer.new(), "Sky")
	layer.layer = -20
	var grad := GradientTexture2D.new()
	grad.gradient = Gradient.new()
	grad.gradient.set_color(0, Color(0.04, 0.03, 0.1))
	grad.gradient.set_color(1, Color(0.25, 0.13, 0.27))
	grad.fill_to = Vector2(0, 1)
	var rect := TextureRect.new()
	rect.texture = grad
	rect.size = Vector2(384, 216)
	_add(layer, rect, "Gradient")
	var stars := Control.new()
	stars.set_script(load("res://scripts/level/stars.gd"))
	stars.size = Vector2(384, 216)
	_add(layer, stars, "Stars")
```
*(from the game)*

* The sky is **infinitely far away**, so it shouldn't scroll at all. A CanvasLayer at −20 is fixed
  to the screen and behind everything.
* `GradientTexture2D` generates a texture from a `Gradient`. `fill_to = (0, 1)` makes it vertical
  (top to bottom). There's no image file. The sky is generated.

```gdscript
func _build_parallax() -> void:
	# Two layers of distant buildings that scroll slower than the camera.
	var layers := [
		["FarCity", 0.2, Color(0.07, 0.06, 0.16), 0.0, 150.0],
		["MidCity", 0.45, Color(0.14, 0.12, 0.26), 90.0, 166.0],
	]
	for l in layers:
		var p := Parallax2D.new()
		p.scroll_scale = Vector2(l[1], 1.0)
		p.repeat_size = Vector2(384, 0)
		p.repeat_times = 3
		p.z_index = -10 if l[0] == "FarCity" else -9  # behind the street buildings (-5)
		_add(level_root, p, l[0])
		var x: float = l[3]
		var i := 0
		while x < l[3] + 384.0:
			var region := BUILDING_YELLOW if i % 2 == 0 else BUILDING_BURGER
			_sprite(p, region, Vector2(x - 40.0 if x > 300 else x, l[4]), l[2])
			x += region.size.x - 10.0
			i += 1
```
*(from the game)*

### 🔤 Parallax
Objects far away seem to move slower as you move. `Parallax2D.scroll_scale = 0.2` moves its
children at 20 % of the camera's speed, so they look distant. At 0.45 they look closer. Two layers
at different speeds create convincing depth for free.

* `repeat_size = (384, 0)` + `repeat_times = 3`: the 384 px strip of skyline **repeats
  horizontally**, so it never runs out however far you walk.
* **Silhouettes by tinting:** the same building art, multiplied by a very dark purple, becomes a
  distant skyline. The farther layer is darker, which is atmospheric perspective.
* Each layer sits a little lower (`150`, `166`), so the mid layer overlaps the far one.

```gdscript
	var tint := CanvasModulate.new()
	tint.name = "NightTint"
	tint.color = Color(0.8, 0.77, 0.95)
```

**`CanvasModulate`** multiplies the colour of **everything on its canvas** (the main world, not the
CanvasLayers). One node gives the whole street a cool, night-time cast, while the HUD keeps its
true colours.

## Lesson 10.7 — Stars and moon with `_draw()`

`scripts/level/stars.gd`:

```gdscript
extends Control
## Draws a twinkling star field for the night sky (no texture needed).

var _stars: Array[Vector3] = []  # x, y, phase
var _time := 0.0


func _ready() -> void:
	var rng := RandomNumberGenerator.new()
	rng.seed = 7
	for i in 70:
		_stars.append(Vector3(rng.randf_range(0, 384), rng.randf_range(0, 130), rng.randf() * TAU))


func _process(delta: float) -> void:
	_time += delta
	queue_redraw()


func _draw() -> void:
	# Moon
	draw_circle(Vector2(300, 38), 14, Color(0.95, 0.92, 0.8))
	draw_circle(Vector2(306, 34), 13, Color(0.08, 0.07, 0.16))
	for s in _stars:
		var a := 0.4 + 0.6 * absf(sin(_time * 1.5 + s.z))
		draw_rect(Rect2(s.x, s.y, 1, 1), Color(1, 1, 1, a))
```
*(from the game)*

### 🔤 Custom drawing
Any `CanvasItem` (Node2D or Control) can draw shapes in `_draw()` with `draw_circle`, `draw_rect`,
`draw_line`, `draw_texture`, `draw_string`…

* `_draw()` runs **once** and the result is cached. To animate, call **`queue_redraw()`**, here
  every frame.
* **Packing data in a `Vector3`:** x and y are the position, and z is a random **phase**. It's a
  compact trick. A small class would be clearer for more fields.
* **Twinkle:** `0.4 + 0.6 × |sin(1.5t + phase)|` makes alpha oscillate between 0.4 and 1.0. The
  random phase means each star twinkles out of sync.
* **The crescent moon** is a pale circle with a slightly smaller sky-coloured circle drawn on top,
  offset up and right. Two calls make a crescent.
* `seed = 7` gives the same sky every time. The title screen reuses this script.

## Lesson 10.8 — Rain and level bounds

```gdscript
func _build_rain() -> void:
	var layer := _add(level_root, CanvasLayer.new(), "Rain")
	layer.layer = 5
	var drop := GradientTexture2D.new()
	drop.width = 1
	drop.height = 7
	drop.gradient = Gradient.new()
	drop.gradient.set_color(0, Color(0.7, 0.8, 1.0, 0.0))
	drop.gradient.set_color(1, Color(0.7, 0.8, 1.0, 0.6))
	drop.fill_to = Vector2(0, 1)
	var p := CPUParticles2D.new()
	p.texture = drop
	p.amount = 140
	p.lifetime = 0.9
	p.preprocess = 1.0
	p.position = Vector2(220, -12)
	p.emission_shape = CPUParticles2D.EMISSION_SHAPE_RECTANGLE
	p.emission_rect_extents = Vector2(240, 2)
	p.direction = Vector2(-0.25, 1)
	p.spread = 2.0
	p.gravity = Vector2.ZERO
	p.initial_velocity_min = 260.0
	p.initial_velocity_max = 320.0
	p.particle_flag_align_y = true
	p.modulate = Color(1, 1, 1, 0.5)
	_add(layer, p, "Particles")
```
*(from the game)*

* **The drop texture is a 1 × 7 gradient** from transparent to pale blue: a streak with a soft
  tail, made in code.
* **Emitter:** a wide, thin rectangle above the screen (480 × 4 px), shifted right because the
  rain slants left (`direction (−0.25, 1)`).
* `particle_flag_align_y`: each streak rotates to match its direction of travel.
* `preprocess = 1.0` simulates one second **before the first frame**, so it's already raining when
  the level appears.
* **On a CanvasLayer (5):** rain covers the screen however the camera moves, in front of the world
  and behind the HUD (10).

```gdscript
func _build_bounds() -> void:
	# Invisible walls at both ends of the level.

		var shape := CollisionShape2D.new()
		var rect := RectangleShape2D.new()
		rect.size = Vector2(16, 1000)
		shape.shape = rect
		_add(body, shape, "Shape")
```
*(from the game)*

Invisible `StaticBody2D` walls (default layer 1, world) stop the player walking off either end.

## Lesson 10.10 — The boss arena

`scenes/level/boss_arena.tscn`:

```
BossArena   Node2D (origin: left edge, on the ground)
├── Trigger    Area2D (110, −200), mask 2 → 16×400 strip
├── WallLeft   StaticBody2D (−8, −300) → Shape 16×600, disabled
├── WallRight  StaticBody2D (392, −300) → Shape 16×600, disabled

```

```gdscript
extends Node2D
## A one-screen boss arena. Place its origin at the left edge, on the ground.
## When the player walks in: walls close, the camera locks to the arena,
## the boss drops in and after a short intro the fight starts.
## When the boss dies: walls open and the camera is released.

@export var boss_scene: PackedScene
@export var width := 384.0
@export var reward := "health"  ## Pickup dropped when the boss dies.

var _triggered := false
var _boss: Node2D
var _saved_limits := []

@onready var trigger: Area2D = $Trigger
@onready var wall_shapes: Array[CollisionShape2D] = [$WallLeft/Shape, $WallRight/Shape]


func _ready() -> void:
	trigger.body_entered.connect(_on_trigger_body_entered)
	Game.boss_defeated.connect(_on_boss_defeated)
```
*(from the game)*

* **`@export var boss_scene: PackedScene`**: one arena scene works for any boss. The level builder
  sets which one.
* `width := 384.0` is one screen, so the camera lock shows exactly the arena.

```gdscript
func _on_trigger_body_entered(body: Node2D) -> void:
	if _triggered or not body.is_in_group("player") or boss_scene == null:
		return
	_triggered = true
	_set_walls(true)
	_lock_camera(body.camera)

	_boss = boss_scene.instantiate()
	_boss.global_position = $BossSpawn.global_position
	_boss.arena_left = global_position.x + 8.0
	_boss.arena_right = global_position.x + width - 8.0
	get_parent().add_child.call_deferred(_boss)

	Game.message("WARNING!\n" + _boss.boss_name, 2.0)
	Game.shake(3.0)
	await get_tree().create_timer(2.0).timeout
	if is_instance_valid(_boss):
		_boss.activate()
```
*(from the game)*

The fight's **intro sequence**, step by step:

1. **Guards:** fire once only, and only for the player. (The trigger's mask is already the player
   layer, but checking the group is cheap insurance.)
2. **Close the walls** and **lock the camera**. You're trapped, and the camera frames the arena.
3. **Spawn the boss** 120 px up, so it **drops in**. Tell it where the walls are. Deferred, because
   we're inside a physics callback (`body_entered`).
4. **WARNING banner** plus shake.
5. **Wait 2 s** (the boss is inactive and invulnerable), then `activate()`. Check
   `is_instance_valid` first, because something may have happened during the wait.

> Setting `_boss.global_position` before `add_child` works because the parent (the level) sits at
> the origin, so local and global coordinates match. In general, set `position` before adding, or
> `global_position` after.

```gdscript
func _on_boss_defeated(boss_name: String, is_final: bool) -> void:
	if not is_instance_valid(_boss) or boss_name != _boss.boss_name:
		return
	_set_walls(false)
	var player := get_tree().get_first_node_in_group("player")
	if player:
		_unlock_camera(player.camera)
	if not is_final:
		var p := preload("res://scenes/pickups/pickup.tscn").instantiate()
		p.kind = reward
		p.expires = false
		p.global_position = Vector2(global_position.x + width * 0.5, global_position.y)
		get_parent().add_child.call_deferred(p)
		await get_tree().create_timer(1.5).timeout
		Game.message("AREA CLEAR\nGO  >>>", 2.5)
```
*(from the game)*

* **All three arenas hear every `boss_defeated`.** Each checks that it's about *its own* boss.
  This is a common pattern with a global bus: filter by identity.
* Open the walls, release the camera, and drop the reward in the middle of the arena.
* "AREA CLEAR / GO >>>" after a beat. The final boss skips this, because victory takes over.

```gdscript
func _set_walls(closed: bool) -> void:
	for s in wall_shapes:
		s.set_deferred("disabled", not closed)


func _lock_camera(cam: Camera2D) -> void:
	_saved_limits = [cam.limit_left, cam.limit_right]
	cam.limit_left = int(global_position.x)
	cam.limit_right = int(global_position.x + width)


func _unlock_camera(cam: Camera2D) -> void:
	if _saved_limits.size() == 2:
		cam.limit_left = _saved_limits[0]
		cam.limit_right = _saved_limits[1]
```
*(from the game)*

* Walls toggle via `disabled` on their shapes, deferred (physics state change).
* **Save and restore** camera limits instead of hard-coding "0 and 3776". The arena doesn't need to
  know the level's size. Because `limit_smoothed` is on, the camera glides into and out of the
  arena.

📝 **Recap**
* Level = data tables + builder code. Seeded `RandomNumberGenerator` = varied but reproducible.
* `TileMapLayer.set_cell(map_coords, source_id, atlas_coords)`.
* Build a tree in code → set `owner` on every node → `PackedScene.pack` → `ResourceSaver.save`.
* Depth: tree order < `z_index` < `CanvasLayer`. `Parallax2D` for distance. `CanvasModulate` for
  mood.
* `_draw()` + `queue_redraw()` for procedural graphics. Particles for rain.
* Boss arena: trigger → walls + camera lock → spawn → await → activate. Filter bus signals by
  identity, and save and restore state you change.
